Deskripsi & Analisis Sistem Pelacak

Dokumentasi operasional integrasi mikrokontroler dengan cloud database

Cara Kerja Perangkat

NavixTracker memanfaatkan mikrokontroler ESP32 sebagai otak utama yang terhubung dengan modul GPS Ublox NEO 6M. Modul GPS menangkap sinyal satelit secara periodik untuk mendapatkan koordinat bumi presisi tinggi (garis lintang dan garis bujur).

Arsitektur Komunikasi Data

Setelah koordinat berhasil didapatkan dan divalidasi oleh ESP32, data dibungkus dalam format JSON lalu dikirimkan secara nirkabel memanfaatkan modul Wi-Fi internal mengarah ke Firebase Realtime Database. Proses pengiriman dirancang dengan latensi rendah untuk memastikan pemantauan posisi aset terjadi secara seketika ("real-time").

Spesifikasi Perangkat Keras

  • ESP32 Development Board: Sebagai unit pemroses dan pengirim data via Wi-Fi.
  • Ublox NEO 6M GPS Modul: Sensor pembaca titik koordinat satelit bumi.
  • GPRS SIM800L: memberikan kemampuan komunikasi seluler berbasis jaringan 2G kepada perangkat mikrokontroler (seperti Arduino, ESP32, atau Raspberry Pi).
  • Sistem Catu Daya: Regulasi daya konstan untuk kestabilan sensor antena GPS.
