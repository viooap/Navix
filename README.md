# Navix
Navix adalah proyek IoT pelacak kendaraan berbasis cloud yang mengintegrasikan perangkat keras GPS atau 
mikrokontroler di dalam armada dengan berbagai sensor fisik melalui jaringan internet menggunakan protokol HTTP 
atau MQTT . Di dalam kendaraan, sistem Navix bertugas mengumpulkan data telemetri penting secara real-time—mulai dari koordinat lokasi.

# Hardare / ( Alat )
| Console / Module       | Fungsi |
| :-------               |:---|
| Esp32 Devkit V1        | Bertindak sebagai pusat kendali (controller) yang mengatur seluruh jalannya sistem Navix.|
| Modul Gps Ublox Neo 6m | Menentukan posisi geografis kendaraan secara akurat di permukaan bumi.  |
| Modul Sim800l           | Menyediakan koneksi internet seluler ke perangkat agar bisa mengirimkan data ke komputasi awan (cloud server).  |
